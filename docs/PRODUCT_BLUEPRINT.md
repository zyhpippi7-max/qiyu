# 奇遇AI 产品蓝图 v0.1

## 产品定位

奇遇AI是一套“AI内容生产 + 视频导演工作流 + Windows自动执行 + 小程序远程控制”的内容运营平台。

核心闭环：

1. 用户通过网站或小程序用自然语言提出目标。
2. LLM把目标转换为结构化执行计划。
3. 图片、视频、TTS、ASR与混剪服务完成内容生产。
4. 用户审核高风险动作。
5. Windows自动化助手在用户电脑执行发布、微信与平台操作。
6. 服务器记录进度、日志、截图、成本与结果。

- 微信联系人、消息、标签、朋友圈、SOP与自动回复
- 截图、日志、重试和状态回传
- 受控的打开网页、打开软件、输入与快捷键动作

## AI与媒体服务

- LLM与图片：用户自建Sub2API
- 视频生成：Seedance Provider Adapter
- 图片生成：GPT Image Provider Adapter
- TTS：自建IndexTTS2服务，云GPU弹性扩容
- ASR：自建Faster-Whisper/FunASR服务
- 视频合成：本地FFmpeg + 阿里云ICE
- 文件存储：统一Storage Adapter，首选OSS以配合ICE

## AI视频导演状态机

`draft → scripting → storyboarding → keyframes → generating_shots → voice → subtitles → composing → review → publishing → completed`

每个镜头独立保存提示词、参考图、模型参数、版本与结果。单镜头失败时只重试该镜头。

## 安全原则

- API密钥只保存在服务端加密配置中。
- 平台账号凭证优先保存在用户电脑。
- 有外部影响的任务默认人工确认。
- 自动化命令使用白名单，不开放任意Shell执行。
- 每个任务有用户、设备、权限、超时、幂等键和审计日志。
- 微信与内容平台自动化提供频率限制和风险提示。
