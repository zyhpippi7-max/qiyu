# 原系统子界面与交互矩阵

以下清单来自原系统前端构建文件、页面组件和接口调用，不代表照搬其代码；奇遇AI只借鉴信息架构与业务流程，界面和实现独立重建。

| 模块 | 原界面主要能力 | 奇遇AI需要实现的真实交互 |
| --- | --- | --- |
| 工作台 | 总览、快捷入口、进行中任务 | 从真实任务、素材、设备表汇总，空库全部为 0 |
| 数据分析 | 内容、发布、增长、线索统计 | 时间筛选、指标筛选、真实聚合、导出 |
| 智能体 | 专家对话、会话历史 | 新建会话、选择智能体、流式消息、历史记录 |
| AI员工 | 岗位角色、状态、工作流 | 新建、编辑、启停、绑定知识库和工作流 |
| 视频剪辑 | 素材到成片的创建流程 | 创建项目、上传素材、脚本、分镜、字幕、配音、导出任务 |
| 素材库 | 上传、分类、筛选、预览 | R2上传、元数据、搜索、预览、下载、删除 |
| 本地文件 | 桌面端文件选择与同步 | 设备授权目录、同步状态、加入素材库 |
| GPT Image 2 生图 | 提示词、尺寸、数量、历史 | 调用用户中转API、任务状态、结果入库 |
| 电商生图中心 | 商品图工作流 | 上传商品、选择场景、批量生成、审核、导出 |
| 作品库 | 视频作品统计、上传、预览 | 真实作品为 0 起步；上传、筛选、预览、下载、删除 |
| AI专家 | 专业角色管理 | 新建、编辑、启停、提示词、知识库与模型配置 |
| 知识库 | 文件和知识条目管理 | 上传、解析、检索、编辑、删除、调用统计 |
| 公域获客 | 关键词、平台、发现任务 | 条件配置、设备执行、结果去重、人工审核、导出 |
| 主动激活 | 客户分组激活 | 选择客户、模板、发送时间、审批与执行记录 |
| 朋友圈营销 | 内容和发布计划 | 文案、图片、账号、排期、设备执行、失败重试 |
| 微信消息 | 联系人和会话 | 设备同步、会话列表、发送任务、状态回执 |
| 自动回复 | 关键词/AI回复、新好友问候 | 策略CRUD、启停、关键词、AI专家、黑名单、限额 |
| 任务监控 | 统一任务状态 | 搜索、筛选、日志、暂停、取消、重试 |
| 设备管理 | 桌面客户端与在线状态 | 绑定码、能力、权限、心跳、日志、版本更新 |
| 账号绑定 | 平台登录与设备归属 | 选择平台、选择设备、扫码登录、状态检查、解绑 |
| 卡密兑换 | 卡密兑换与记录 | 校验、兑换、额度入账、历史记录 |
| AI充值 | 额度、套餐与订单 | 套餐选择、订单、支付状态、用量明细 |
| 记账报税 | 企业和服务订单 | 企业资料、服务套餐、票据、进度、订单 |
| 企业中心 | 企业、成员和合同 | 企业资料、成员权限、合同、服务授权 |
| 设置 | 模型、存储、通知、安全 | 用户自己的API、模型映射、R2/OSS/COS、通知与自动化权限 |

## 实现原则

- 不显示演示记录；没有真实数据时统一显示 0 和空状态。
- 创建、编辑、删除、筛选和状态变化必须写入数据库。
- 图片、视频、音频和文档存对象存储，数据库只保存元数据。
- 自动化任务必须经过用户授权、审批和可追踪日志，不把网页按钮伪装成已执行。
- 外部模型和平台未配置时明确显示“未配置”，不得返回伪造结果。
