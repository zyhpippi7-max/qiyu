# 项目方准备清单

## 现在需要

- 确认第一版网站的视觉方向和首页信息结构。
- 提供Sub2API的接口文档或示例请求，不需要在聊天中发送正式密钥。
- 提供Sub2API可用模型清单，标注文本、视觉、图片生成和工具调用能力。
- 确认第一期优先打通的平台，建议从抖音发布开始。
- 确认Windows助手的第一期目标系统版本，建议Windows 10/11 64位。

## 设计确认后需要

- 为开发环境生成一个可限额、可随时撤销的Sub2API专用Key。
- 开通阿里云OSS测试Bucket；ICE等进入视频阶段再开通。
- 提供Seedance实际供应商的API文档、测试Key与额度。
- 准备一台Windows测试电脑和测试平台账号。

## 暂时不需要

- 不需要现在打开RunPod。
- 不需要现在购买大量GPU时长。
- 不需要现在开通微信支付、短信、Coze或全部阿里云视觉服务。
- 不需要提供生产服务器或正式数据库权限。

## 到TTS/ASR阶段需要

- 5090机器的可用时段与远程部署方式。
- 一段已获授权的普通话参考音频，用于IndexTTS2测试。
- RunPod或端脑云账号仅用于备用和并发压测。
