# 两名员工工作分配

## 共同目标

在不触碰生产环境、核心自动化和数据安全的前提下，完善 `xcx.qiyuai.com.cn` 的页面细节、响应式体验和私域功能交互。当前所有修改只保存在员工本地，不提交、不推送、不创建 PR。任何源码修改都必须先把方案交负责人看完，并取得明确同意。

## 员工 A：视觉与响应式负责人

GitHub 用户名：`zyhpippi7-max`

专属说明：`docs/EMPLOYEE_A_TASKS.md`

预留远程分支：`employee-a/1-ui-polish`（当前不得推送）

允许范围：

- `app/globals.css`
- 页面中纯展示性质的文案、图标、间距和布局
- 各分辨率截图及视觉验收记录

首批任务：

1. 统一主页面字号、行高、按钮高度、输入框高度和卡片间距。
2. 检查 1366×768、1440×900、1920×1080 三种尺寸，确保弹窗完整居中且可滚动。
3. 修复功能模块过小、文字难以阅读、弹窗顶部被裁切的问题。
4. 统一左侧菜单、顶部栏、空状态、加载状态和错误状态的视觉样式。
5. 提交前后对比截图，不改变接口、字段和业务逻辑。

验收标准：

- 主要正文不小于 14px，辅助文字原则上不小于 12px。
- 弹窗最大高度不超过视口，顶部和底部均留有安全间距。
- 三种指定分辨率无横向溢出、遮挡或不可点击区域。
- 不修改 API、桌面端、数据库、部署配置和依赖。
